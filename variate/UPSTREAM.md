## Intentional divergence

- Prime-native SKILL/AGENTS contract; no hook frontmatter or cross-agent installer.
- Preview remains foreground under a tracked bash handle, not a detached process.
- One-shot requests with explicit consumer identity, recoverable claims and terminal
  acknowledgements; no waiting loop, wake job, or heartbeat writer.
- Keep requests capture server-derived hashes; stale decisions and unresolved asks
  prevent cleanup. End owns final acknowledgement before workspace removal.
- Focused file, symlink, attachment ownership and static-serving safety repairs;
  tests protect hand edits, original archives, mode preservation and path boundaries.
- The project brief overrides upstream aesthetic absolutes; meaningful variants,
  accessibility, real copy and native build/visual verification remain required.
- Removed marketing site, evaluation prompts that require polling, cross-agent display
  metadata and installer. Runtime/client and license assets remain self-contained.

Treat updates as reviewed code changes. Never pull over this directory blindly.
Compare with the pinned upstream source, preserve local regression coverage, rerun
bounded native/browser tests, then validate, commit, push and verify the configured
prime-agent-skills remote. Audit evidence and limitations are in AUDIT.md.
