# Tutor

A small, optional teaching workflow for Prime Agent. It can be selected naturally
for a tutoring request; the user does not need to remember a command.

Try: “Teach me how this parser handles missing fields. Use this spec and give me
one exercise.” The default is chat, not files or a course workspace.

For continuity: “Save my lesson and evidence in this selected course folder.”
The records separate exposure, claimed knowledge, and demonstrated performance.
They remain learner-owned documents, not agent behavioral memory.

- [Workflow](SKILL.md)
- [Worked lesson and optional record format](references/lesson-record.md)
- [Source and adaptation notes](UPSTREAM.md)

No scripts, dependencies, browsing setup, or scheduled practice are included.
The workflow is not evidence of educational effectiveness or certification.
