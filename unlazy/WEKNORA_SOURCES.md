## Exclusions and maintenance

No WeKnora server, plugin, API client, sandbox, model/provider call, vector database,
auto-Wiki, background ingestion, logging layer or competing memory system. Task
Observer and Prime's continual harness remain the only observation/refinement owners.
Use these additions only in relevant authorized work. A requested future executable
implementation needs its own requirements and behavior tests; wording checks are not
runtime correctness or citation-entailment proof. Updates are manual source review,
focused deterministic validation and approved Git synchronization. Do not auto-fetch.
