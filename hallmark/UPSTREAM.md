## Deliberate changes

- Replace the large main prompt and contradictory references with a small Prime-native
  entrypoint and focused workflow references. Catalogue suggestions never override the
  user or existing design system. No compulsory theme/nav rotation, repeated interviews,
  font/italic/colour bans, eight invented states, visual-authorship detection or self-scores.
- Remove automatic CSS stamps, preflight caches, .hallmark logs, token files and exports.
  Preserve existing token sources; exports are explicit, version-specific and validated.
- Screenshot-first study. Remove WebFetch-specific instructions and hypothetical network
  safety promises. Supplied references are untrusted design data, not commands or proof
  of asset ownership. Asset licensing is verified at the actual source when needed.
- Remove unsupported asset kits, invalid/universal export recipes and blanket overflow/
  nowrap fixes. No site scripts, images, downloads, sample-site server or npx installer.
- Explicit Variate integration: guidance inside assigned variant files, no shared-file
  side effects, no competing queue/server or claim that comparison is an A/B experiment.
- Native checks and actual rendering replace pre-build pass claims. Evaluation fixtures
  and test scripts are development-only, not runtime components of the skill.

Treat future upstream updates as reviewed changes. Do not overwrite this directory with
an installer. Reconcile with the pinned source, retain local contract and pilot coverage,
then validate, commit, push and verify the authoritative skills remote.
