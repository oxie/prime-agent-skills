Curated from Cathryn Lavery, diagram-design `references/type-loop.md` at `3b446333f164174a571106673f943c58df282ff8` (MIT). See [retained license](../LICENSE.diagram-design). This Prime adaptation changes prescriptive styling and preserves evidence over layout.

## Choose this type

A genuine returning cycle; a shared hub is useful only when repeated passes accumulate shared state.

This is a selectively loaded authoring brief, not a new deterministic renderer. Follow [design](design.md); typed Archify contracts remain authoritative in typed mode.

## Evidence to collect

Ordered stations, closing return, feedback/write-back relationships and any durable hub state.

## Geometry and reading order

Place stations around a circle using theta = -pi/2 + 2*pi*i/N. Use consistent circular arcs between station edges, not through boxes. A real hub sits in the middle with distinct dashed write-back spokes, separate from the cycle path.

## Honesty and review

Do not invent a hub, five stations or feedback to fill a layout. A cycle without stored shared state omits the hub and says so. A process that actually ends belongs in flowchart/process. Arrow direction and write-back meaning must survive without motion.

Check text/connector clearance at the actual output size. Preserve required facts when splitting a dense view; name omissions and cross-view relations. Static lint does not prove semantic or geometric correctness.
