# Rough ink with an offset spot fill

An optional illustration direction for an editorial page, guide or quiet product
story. It combines a loose monochrome contour with a single flat shape in one accent
color. Choose it for the brief, not as a compulsory image style or a reason to replace
approved photography, brand marks or the host palette. Image owns asset production;
Hallmark/Cinematic UI own placement and readable HTML.

## The drawing grammar

- **Contour:** describe the subject with a rough, mostly continuous ink line. Let
  selected turns and joins feel hand-drawn; retain enough silhouette to read at the
  placement size. “Continuous” describes the visual gesture, not a claim that every
  drawing is one mathematically uninterrupted path.
- **Spot:** use one simple flat filled shape, behind the contour and slightly offset
  from it. Let a small exposed edge make the two layers visible, like a deliberate
  registration shift. The shape supports the subject; it does not need to fill it
  perfectly or become a second detailed drawing.
- **Paper:** leave negative space around the subject and, when needed, on the side
  that will meet real page text. Use approved host paper/ink/accent roles. A muted
  accent is one option; saturation is an art choice, not a universal prohibition.
- **Hierarchy:** the ink carries recognition and the spot carries emphasis. Do not
  use the accent alone to communicate a required state. Keep the illustration out
  of the text plane if its lines interfere with reading.

Start with a clear subject/action. For a fictional repair-guide illustration, an
open notebook with a thread resting across the page can suggest recording a repair.
This is an original prompt example, not an assertion that a generated image exists.
A complex pile of props would weaken the quiet contour/spot relationship.

## Worked subject, composition and placement prompt

```text
Asset role: editorial illustration for a fictional repair guide, not evidence of
real operations. Static landscape composition, with an open notebook low on the
right and a single thread curving across its open page. No logo, labels or lettering.
Drawing: rough charcoal-colored ink contour; use a loose continuous gesture for
the notebook silhouette, with only enough interior strokes to show the page fold.
Spot: one flat, softly colored oval behind the notebook, shifted slightly toward
the lower right so a visible edge peeks beyond the contour. No extra colored props.
Space: leave the left side mostly paper-colored for separately composed HTML copy.
Keep the notebook's binding and thread inside the intended crop; no baked-in text
or controls. Use the approved host's paper, ink and accent color roles.
Placement: inspect first at the actual editorial slot size, then in the narrow crop.
If an inline heading pill is used instead, crop a recognizable detail and leave the
heading complete without the image. That is a different placement, not a free crop.
Output boundary: prompt-only until drawing or authorized generation is performed.
No provider invocation, font acquisition or publication is requested by this brief.
```

## Revision choices that preserve the idea

| Observed issue at placement size | Focused revision | Keep fixed |
|---|---|---|
| The object is unrecognizable | Simplify interior strokes or strengthen the outer contour; inspect again at actual size. | Subject, action and approved palette. |
| The fill reads as accidental misalignment | Reduce the offset or place its exposed edge next to a quiet contour segment. | One spot shape behind the ink. |
| The fill steals attention from the drawing | Reduce its area or choose a quieter approved accent role. | The recognizable silhouette. |
| The drawing looks too sterile | Add a few purposeful irregular turns rather than noise across the whole image. | Readability of the defining edges. |
| Roughness becomes dirt at small size | Remove minor marks and widen crowded gaps. | The loose gesture; do not blur the whole image. |
| The crop cuts away the action | Move the crop or choose a wider slot; make a separate detail crop only when it still communicates. | The original approved master. |
| The subject competes with copy | Move it toward the reserved side or reduce occupied area. | Exact page text and its reading order. |

Use a named change such as “smaller spot, same contour and crop” rather than asking
for a globally “better” result. Keep the prior approved version under the project's
normal conventions. For reference-led revisions, [brand worlds](brand-worlds.md)
explains how to separate a visual-language reference from the current content anchor;
there is no need to create another campaign framework for a single illustration.

## Production and evidence boundary

Use owned or approved art. A prompt does not grant rights to a named artist's exact
signature, a brand or third-party imagery. Generation, when separately authorized,
still needs actual output inspection; neither a prompt nor a model name guarantees
line quality, a single fill or correct anatomy/objects.

For web use, keep meaningful copy and controls in semantic HTML. Decorative images
use empty alt text; a meaningful standalone illustration needs an alternative that
conveys its role, not just its ink style. Reserve image dimensions and inspect narrow
reflow, failed media, actual-size contour clarity and crop safety. A local SVG may
have editable paths, but this study is not a production identity master. When using
inline SVG, map fill/stroke roles locally; external `<img>` SVG does not inherit the
host page's CSS variables. Do not promise recoloring merely by setting a parent token.
Report prompt-only versus authored/generated asset, what was actually viewed and
what remains untested. This reference adds no runtime, provider or animation.
