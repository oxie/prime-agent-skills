# Questionnaire

Draft a focused request to someone who holds facts the user needs. Prime can
select this skill for a matching request without a named invocation.

Try: “Draft questions for our service owner. We need to decide whether launch
capacity is sufficient. Use the attached load-test results; do not send it.”
Supplied context is reused. Clarification is limited to gaps that change the draft.

- [Workflow](SKILL.md)
- [Usable example and coverage guide](references/draft-guide.md)
- [Source and adaptation notes](UPSTREAM.md)

The default output is Markdown in chat. Files require an authorized output scope.
No scripts, dependencies, automatic sending, or research campaign are included.
