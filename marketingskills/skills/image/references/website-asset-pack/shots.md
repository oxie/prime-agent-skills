# Prompt and timeline plan

These are original prompt drafts, not commands. Reference names identify the
hypothetical inputs in [the brief](brief.md), not provider IDs. Nothing is submitted.

## Still S1 / prompt-r1

Create a wide concept view of the imagined desk light using object-front-r1 for
visible identity only. Hold its silhouette and existing visible details. Use
look-board-r1 only for broad upper-left illumination, neutral background and a
soft contact shadow. Keep the object on the right with quiet space at left for
separate HTML copy. No added text, logo, people or unobserved product details.

The narrow variant is a reviewed crop from the accepted master where possible,
not a new object generation. The model's requested ratio is not proof of output size.

## Motion V1 / prompt-r1

Starting from the accepted S1 master, make one six-second concept shot. Hold the
light's visible structure and label position. Move the camera slowly closer with
no orbit; do not expose unseen surfaces. Keep lighting and the backdrop stable.
No cuts, added objects or baked-in text. Finish on the same visible face at a
closer scale. Audio is not required. Inspect the resulting clip before use.

The duration is a requested target; actual supported parameters and decoded output
must be checked in real production. If an acceptable clip cannot be made within
approval, keep the still and disclose the missing motion.

## Delivered timeline

One optional film, three chapter intervals: overview [0,2), detail [2,4), closing
view [4,6]. There are no overlaps or connector jobs in this example. Their durations
sum to six seconds. The player would seek the same film using those intervals;
it must not replay the entire six seconds once per chapter. For an ordinary hero
without scroll chapters, use one continuous clip instead of adding a controller.

Static delivery retains a useful overview plus separate copy. If later copy teaches
an additional state, add the relevant approved still/caption; do not assume this
one poster preserves a lesson it never showed.
