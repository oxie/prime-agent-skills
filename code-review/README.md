# Code review

Use for a requested branch, staged, dirty-work or pre-commit review. No named invocation
is required when the task clearly matches. Also use for assessing incoming review
comments via [feedback assessment](references/receiving-feedback.md). Reports are
read-only by default; implementation and publication need applicable authorization.

The skill keeps requirements/correctness and project standards visible separately,
while ranking real risks together. See [SKILL.md](SKILL.md),
[scope recipes](references/scope.md) and [source notices](UPSTREAM.md).
No installer, runtime dependency, tracker setup or automatic commit is included.
