# WikiSkill: two selected debugging examples

Source: https://github.com/ashutoshsinghpr7/wikiskill at
`02fac2c804fe156e43b12c691e4ae527614d63a1`, reviewed 2026-09-15.

[Debugging](references/debugging.md#two-checks-for-misleading-evidence) adds original
local prose on exact-attempt evidence and bounded binary-aware search. It corrects
failure patterns rather than copying the upstream implementation or universalizing
its operational skills. Source identities and current local bytes are recorded in
[wikiskill-provenance.json](wikiskill-provenance.json).

- `wikiskill/harness.py:74-85` and `wikiskill/gating.py:137-166`: proposal freshness
  and task artifact attribution across attempts.
- `wikiskill/backends/codex.py:153-203` and `wikiskill/traces.py:27-40`: newest-session
  selection and stale transcript siblings are not proof of current execution.
- `skills/search-miss-binary/SKILL.md`: binary detection can limit search coverage;
  the local example requires authorized, bounded inspection, not blanket text mode.

No upstream executable code, paper prompt, framework skill, wiki, provider adapter,
model experiment or automatic workflow is bundled. No rejected-proposal guidance or
Task Observer changes are included. Existing skill routing and runtime are unchanged.
Historical source records keep their original identities and verification limits.
Maintain through manual review and normal deterministic checks; these checks do not
establish model effectiveness. Future execution or broader adoption needs separate
authorization.
