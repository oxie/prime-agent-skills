## Selected evidence

ecc-provenance.json records immutable source identities, prior local identities and
current payloads. Source inspection is not runtime validation.

- [Contract-first](https://github.com/affaan-m/ECC/blob/8321021c54d670126ce3b2969d5deb880b4b0c2a/skills/contract-first/SKILL.md):
  consumer jobs and approval ownership, one canonical artifact, derived types/mocks,
  actual response validation and compatibility review. Preserve its small-boundary
  exception and reference/generator trust boundary. We do not copy its monetary
  double example or require a generator, format, documentation tree or new package.
- [AI regression examples](https://github.com/affaan-m/ECC/blob/8321021c54d670126ce3b2969d5deb880b4b0c2a/skills/ai-regression-testing/SKILL.md):
  useful cross-path drift question, but the parity-labelled snippet only exercises
  forced sandbox, and another skips field assertions for empty arrays. The original
  ticket example explicitly requires nonempty path evidence and keeps semantic checks
  separate from schema shape. It is not a reproduced upstream bug or application test.

The addition is selected for independently changing consumers/providers. Existing
Engineering sections retain parser, state, authorization, retry and reconciliation
ownership. The skill entrypoint, description and version stay unchanged: its existing
contract-boundaries route reaches the new section on demand. No global activation,
mandatory review pass, extra agents or measured productivity benefit is claimed.
