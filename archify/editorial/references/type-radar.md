## Choose this type

Profiles across several comparable criteria on an explicit common scale.

This is a selectively loaded authoring brief, not a new deterministic renderer. Follow [design](design.md); typed Archify contracts remain authoritative in typed mode.

## Evidence to collect

Criteria order, normalization formula, scale limits, score direction, series values and missing values.

## Geometry and reading order

Space N spokes equally; angle = -pi/2 + 2*pi*i/N, radius = R*v/S for a zero-to-S scale. Draw common rings and labels outside the perimeter. Differentiate series by line style or markers as well as color. Keep values available in a table.

## Honesty and review

Normalize unlike units explicitly and invert lower-is-better metrics only with disclosure. Polygon area is not a total score and changes with axis order. Do not join missing scores as zero. Prefer a table or small multiples when overlaps hide comparisons.

Check text/connector clearance at the actual output size. Preserve required facts when splitting a dense view; name omissions and cross-view relations. Static lint does not prove semantic or geometric correctness.
