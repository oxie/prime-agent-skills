# Revision and delivery plan

No production output is delivered here. Proposed filenames in pack.json are future
project paths, not existing files and not download URLs. Every output is planned,
every approval and inspection is unperformed, and every source identity is hypothetical.

## Revision exercise

If object-front-r1 is replaced by object-front-r2 with a changed visible label,
review S1 and V1 again. The wide/narrow hero, final clip and clip poster all depend
on that source and cannot retain their old approvals. The independent text-only
footer remains unaffected. The stable IDs S1/V1 do not prove completion of r2.

If only the narrow crop changes, retain the accepted master and wide crop; recheck
the narrow subject boundary and copy placement. A selected take and its encoded
file are distinct revisions: regenerate the poster from the exact served clip.

## Receiving-site checks for real work

- Check actual file presence, dimensions, encoding, duration and measured bytes.
  Replace hypothetical source IDs with approved source revisions and record which
  checks cover those exact bytes. Never fill missing evidence with a sample pass.
- Keep real copy in semantic HTML. Decorative concept media may have empty alt;
  meaningful product details need an observed description or nearby explanation.
- Inspect wide and narrow layouts, relevant keyboard controls, loading/failure and
  reduced-motion behavior through approved local preview tools. No media success URL
  or source-text test establishes these rendered results.
- If the clip is scrubbed, test forward/reverse/jump seeks against the same shared
  timeline, with correct posters and resource cleanup. Keep the still available if
  motion is disabled or fails; no mandatory library or hosted platform is implied.
- Resolve rights, upload permission, budget and actual output selection before use.
  Deploying publicly and listing on a community feed require separate authorization.

This example demonstrates handoff and invalidation semantics, not measured quality,
provider compatibility, an export tool or paid generation.
