# Embedded brand marks only

Query `node <skill-dir>/bin/archify.mjs brands "<name>" --json` for packaged IDs.
Use an ID only when the supplied facts name that real product. Do not infer a brand
from a generic role. Unknown products retain their honest text label with no badge.
Known domain aliases are local lookups, not network fetches.

Prime removes remote capture. `brands capture` and object-form `{url, sha256}` brands
fail before network activity, including during ordinary validate/render/deliver.
Legacy private-network environment flags cannot enable capture.

Retain semantic type and relationships; a logo is never a substitute for meaning.
Bundled paths are optional identifying marks, not a claim of endorsement or rights.
Read [third-party notices](../THIRD_PARTY_NOTICES.md) and per-mark provenance in
`renderers/shared/generated-brand-marks.mjs`. Some marks have attribution,
share-alike or non-commercial terms; confirm suitability for the intended use.
