## Review and changes

Two independent read-only reviews covered CLI/output/evidence behavior and the
HTML/viewer/browser boundary. Their complete artifacts were read before approved
native execution. Review found ordinary object-brand network capture, external
Google Fonts, a default-output resolved-extension gap, and missing SVG/runtime
acceptance in the browser checker. These were corrected in the adaptation.

No concrete executable injection was found in inspected label/template sinks.
Existing escaping, standalone schemas, diagnostics, aliases, staged delivery and
exact-byte receipts remain. Prime adds local-only brand resolution, an offline-oriented
CSP, disabled update/preview compatibility stubs, sandbox-required browser launch,
exclusive random sidecar scratch files, and scoped on-demand instructions.

The full website/release/dev-dependency workflow is not installed. No packages or
browsers were downloaded; no server, watcher, hook, wake job or daemon was started.
Upstream MIT and third-party notices are retained byte-for-byte.

## Limits

This is installation acceptance, not evidence that an agent authors every diagram
correctly. One architecture and a hostile-text fixture received real browser work;
other types received CLI validation/delivery only. Clicks were DOM-dispatched
handler tests, not pointer hit-testing. No full screen-reader, touch, mobile, true
browser-zoom, clipboard, video or export matrix was run. PNG share-card export is
not validation. Supplied topology, source interpretation and trademark rights still
require review. Source-line existence does not prove architectural semantics.

CSP and request observation are not OS-wide egress isolation. Git evidence must use
trusted fully local objects; partial clones can otherwise lazily fetch. Arbitrary
handwritten HTML is active code, not sanitized by the checker. Sandboxed Chromium
is required; the installed snap wrapper fails in this environment, so the tested
existing Chromium binary is used directly without disabling the sandbox.

Upstream extreme raster dimensions and public programmatic video parameters have
incomplete resource caps and error cleanup. These were not broadened or certified.
Use small static exports. File-path checks are not a filesystem sandbox or a
whole-filesystem concurrent transaction. Browser-check sidecars overwrite a known
output namespace, which must be reserved before use.
