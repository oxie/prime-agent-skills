## Geometry and reading order

Use phase headers over aligned component columns, a labeled cluster/container region, and a source zone. Orchestration can span the components it controls; cross-cutting identity/observability notes sit outside with explicit scope. Grow the canvas for extra rows.

## Honesty and review

Do not infer Kubernetes, identity, backup or governance from a canonical example. A full-width bar implies scope, not a network path. Preserve actual connections and define any abstraction; use architecture when this phase-plus-platform composition adds no information.

Check text/connector clearance at the actual output size. Preserve required facts when splitting a dense view; name omissions and cross-view relations. Static lint does not prove semantic or geometric correctness.
