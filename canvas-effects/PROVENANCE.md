# Provenance and boundaries

This is an original Prime Agent canvas-effects specialist. Its scope came from the
user's interest in Canvas UI and a broader expandable visual toolkit. It is not an
authorized port, forked component catalogue or replacement for all effect types.

Reference reviewed: https://github.com/DavidHDev/canvas-ui at
`34b1e46cd8dc56b8a1e7746561104008bdabee5c`. No Canvas UI component implementation,
shader, scraped asset, generated registry artifact or demo media is bundled here.
The original examples use standard rendering techniques and original scene content;
they do not claim identical behavior to the reference project's effects.

The reference project's custom MIT + Commons Clause text permits use within an
application/website/product but restricts redistribution of the components themselves,
including bundles and ports. Do not treat its README wording as unrestricted MIT
permission. Before incorporating its actual code into a future project, review the
exact revision/license and project usage; this skill grants no additional rights.

The local browser verification pattern builds on the previously reviewed Cinematic
UI test workflow and the existing browser-use environment/process helpers. Those
helpers are prerequisites, not copied external application dependencies or newly
installed services. Their test outcomes do not establish GPU-driver performance.

This package's original source/guidance uses the bundled MIT license. Asset-specific
and dependency-specific rights still require review if a future project adds them.
No trademark endorsement, legal clearance, unique-design guarantee or clean-room
legal certification is asserted.
