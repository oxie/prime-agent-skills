replacements for an existing static page: information-first and action-led. The root
verified only the two assigned new variant files changed; live HTML, baseline and
shared tokens were byte-identical. The initial pilot did not need the catalogue because

## Refinements and limits

Independent review led to explicit implementation-only build checks (read-only audit/
study cannot write build artifacts), accurate font-configuration wording, and stronger
structural pilot assertions. Four routing scenarios were reviewed statically, not
counted as executed model tests: complete existing-system brief, read-only audit,
localhost URL study, and comparison requiring shared CSS.

This is one model-guided existing-system pilot, not a statistical efficacy study,
proof of automatic routing on every prompt, or exhaustive component/framework testing.
The static fixture has no framework build pipeline or backend. Actual glyph use,
all controls/assistive technology, true browser UI text zoom, touch devices, screenshots
as prompt-injection tests, export consumers and greenfield generation were not validated.
The font-scaling test is labelled as such, not browser-zoom certification. Explicit
reload in this pilot is deliberate; Variate's separate test covers reload fallback.
Other projects still need their own native build and visual checks. URL-only study
requests a screenshot; themes remain unmeasured suggestions until used and checked.
