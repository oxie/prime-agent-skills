# Select a direction, not a catalogue

Read this index first when the brief leaves art direction open. Local IDs below
are navigation labels, not components, scores or upstream IDs. They let a decision
note say what was chosen and why. None is mandatory.

## Bound the search

- Start from the visitor's action, existing content and brand. Is the useful change
  a frame, a reading rhythm, a light treatment or an interaction? Name that problem.
- Choose one row below that addresses it. Inspect its suggested craft entries.
  Compare one nearby alternative only if it resolves a real uncertainty. A requested
  broader exploration can widen this; do not read every file by default.
- Keep one recommendation unless alternatives were requested. Retain familiar
  grids, recurring patterns and brand colors when they work. Stop when further
  options are merely cosmetic. Do not consult project history to enforce novelty.
- If nothing fits, use the existing layout and make a small authored decision from
  evidence. An empty pool is not a reason to invent a director or add an effect.
- Name the loss as well as the gain: e.g. “a wide landscape gives context, but
  needs a separate narrow crop and moves less information above the fold.”

## Direction routes

| Content need / desired attention | Composition | Type | Light/material | Rhythm | Avoid when |
|---|---|---|---|---|---|
| Daylit cultural programme; welcome, then browse | C2 framed stage or C4 reading room | T2 editorial + T4 captions | L1 diffuse daylight, L5 paper | P1 establish → encounter → invitation | Important dates disappear below an oversized empty hero |
| Documentary essay; context becomes a personal detail | C3 landscape → detail, C4 body | T2 + T4 | L1 or L2 soft side light; unfiltered approved images | P2 wide → close → context | There is no meaningful source content to carry the story |
| Precise architecture/product portfolio; inspect object and process | C1 weighted split, C6 paired views | T3 measured sans + T4 | L2 directional light, L6 solid mineral/metal | P3 recurring frame / changed scale | Ornament could be mistaken for specifications or measurements |
| Intimate archive; material and memory | C4 reading room, C8 sequenced fragments | T2 + T5 quotation | L5 paper, L2 warm side light | P4 montage → quiet hold | Small angled scraps would obscure essential text |
| Bold cultural launch; a clear title and programme | C5 type monument, C7 triptych | T1 display + T3 support | L4 flat chromatic field | P5 sharp section cuts without flashing | A long legal/product name cannot survive monumental type |
| Night-time object/stage; one lit subject | C2 framed stage, C1 detail split | T3 or T1 | L3 practical glow on an opaque stage | P3 detail sequence, optional M1 finite light cue | Dark surfaces or glow conflict with brand/readability |
| A real catalogue or dense application with a cinematic request | Existing functional grid; C4 only for intro | T3 + T4 | Existing tokens; at most a scoped L2 accent | Immediate access, no narrative gate | Never substitute this for filtering, forms or operational UI |

Read only the selected entries in [composition](composition.md),
[typography](typography.md), [light/material](light-material.md) and
[pacing/motion](pacing-motion.md). For page-level synthesis, choose the closest
[worked direction](worked-directions.md), not all examples.

## The editing test

A thumbnail/wireframe should show a priority. The unstyled reading order should
still make sense. Remove a decorative layer: if the thesis survives and readability
improves, leave it out. If “more cinematic” is requested, first change scale,
framing, density or image direction. Motion is not the automatic next step.

For a site, describe what repeats (shell, type roles, caption style, framing rule)
and what varies with page purpose. Do not delay shared design-system work to force
unique pages. A film, genre or director name is a research lead, not a lookup key.
