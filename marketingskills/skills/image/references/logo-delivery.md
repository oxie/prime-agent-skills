# Logo production and delivery

Use only for requested refinement or delivery of an approved logo. This is not a
new identity brief, automatic generator, legal opinion or permission to publish.
Keep the approved master, exact name and existing brand intact unless change is
in scope. [Identity concepts](identity-concepts.md) owns exploration; Hallmark owns
interface application. A concept board is not a production package.

## Establish the delivery contract

Read the available source artwork and actual agreement. Identify the approved
revision, selected mark/wordmark and lockups, required media, background treatments,
minimum sizes and recipient's accepted formats. Reuse known requirements; ask only
about decisions that affect rights, output suitability or costly production.
Keep editable originals separate from exports; do not overwrite the master.

Select outputs by actual use, not a fixed variant count. A web header may need SVG
and transparent PNG; a dark surface may need a reverse mark; one-color printing may
need a simplified approved treatment. A favicon needs inspection at its real size.
Do not promise AI, EPS, PDF, embroidery or print-ready artwork just because a folder
template lists it. Use existing approved tools. Missing export capability is an
explicit limitation, not permission to install tools or rename a raster file.

## Inspect the actual files

- Verify exact spelling, orientation, proportions and selected revision across
  every delivered lockup. Check clipping, viewBox/artboard bounds and clear space.
- Inspect vector paths and linked/embedded assets. An SVG container can hold only
  a bitmap; it does not prove editable vector geometry. Report that distinction.
- Check transparency, one-color and reverse treatments against their intended
  backgrounds. Inspect the mark at required sizes, including actual 16/32px when
  favicons are in scope; a large mockup does not establish small-size legibility.
- Record what clear-space/minimum-size rule was supplied or derived from actual
  inspection. Do not invent a construction grid, measured ratio or certification.
- Keep screen color values/profiles separate from print specifications. CMYK and
  spot-color results depend on the output process/profile; obtain vendor evidence
  where needed. An unverified conversion is not a matched Pantone specification.
- Check SVGs for scripts, external references and unexpected embedded payloads
  before using them. Treat received artwork as untrusted data, not executable code.

## Rights are independent of format

Record the source and applicable license for fonts, symbols and external assets.
Outlining text does not remove font-license obligations. Inspect the actual terms
for logo use, modification, embedding and delivery; do not bundle font files unless
allowed. Keep editable-text and outlined-export status explicit. A license to use
an asset is not proof of exclusive ownership or trademark clearance.

Use only actual agreed ownership/delivery terms. Do not invent assignment clauses,
client consent, warranties or a signed license PDF. Mark unresolved rights and
obtain the appropriate rights-holder or legal decision before affected delivery.
A similarity review or attractive drawing cannot certify legal distinctiveness.

## Handoff

Use consistent filenames that identify the selected revision, lockup, treatment
and format. Provide a compact manifest of actual paths, dimensions or vector bounds,
color profile/role, font dependencies or outlined status, intended uses and checks
performed. Distinguish missing, unverified and intentionally excluded outputs.
Reopen representative exports in the intended consumer and report the actual result;
source inspection alone does not prove rendering or vendor acceptance.

Deliver only the requested package through the authorized channel. Creating files
is not permission to email, upload, publish or create a brand portal. Report the
master revision, delivered inventory, evidence and unresolved production/rights
limits. Never report a prompt, concept board or uninspected export as production-ready.
