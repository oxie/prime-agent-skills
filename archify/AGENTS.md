# Archify maintenance scope

Read SKILL.md and UPSTREAM.md before changes. Use the target project's Node CLI,
not Python-kernel imports. No dependency installation is required for retained tests.
Preserve labels/JSON escaping, generated schemas, diagnostics, input aliases,
staged delivery and exact-byte receipts. Do not re-enable network capture, external
fonts, updates, watchers or sandbox bypasses as compatibility fixes.

All work is on demand. Use recorded foreground process handles and bounded checks;
no hooks, schedules, daemons or agent-wakeup loops. Tests and previews must clean
owned profiles, temp projects and processes. Inspect exit codes. Read every delegated
atomic result before accepting it. Never claim browser evidence from static checks.

Validate, commit, push and independently verify the configured remote before claiming
skill/instruction synchronization. Do not place credentials in logs or repository files.
