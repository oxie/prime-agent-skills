## Original selection, not an installation

The [optional reference](references/reference-driven-3d.md) is newly authored Prime
guidance under this owner's MIT license. No upstream implementation, fixtures,
images, prompts, generated geometry or media are bundled. The license copy is an
attribution record, not a relicensing of upstream code. Source and input rights
remain distinct; screenshots, likenesses and branded assets need their own review.

Selected ideas: observation versus hidden-shape inference; camera/projection-aware
comparison; separate appearance and structure inspection; feature-scale evidence;
defect-specific positive/negative controls; and revision-bound acceptance. The
fictional desk-lamp case is an original proposed check, not an upstream example or
an executed experiment. Existing Engineering References owns general evaluator and
approval contracts; this does not introduce a second workflow or memory store.

Corrections matter: distinct-Z counts are not proof of volume; beauty-render
subtraction is not exact frontmost visibility; dark-pixel buckets cannot generally
separate albedo from shading; silhouette IoU measures mask overlap, not a universal
percentage of outline information. Do not import fixed overlap distances, minimum
detail quotas, every-model rig/explode requirements, provisional metric thresholds
or assurances that every written gate is mechanically enforced.

The review found historical-any-success acceptance, missing current-render binding
and required-measurement prose without equivalent continuation checks. The local
reference requires actual applicable current evidence; it does not reproduce those
implementations or promise that prose alone enforces them. Upstream tests were read
as source, not run. No upstream imports, installs, scripts, renders, browser runs,
model calls or provider operations were performed for this integration. Local text,
hash, link, regression and native-loading checks do not establish modelling efficacy.
