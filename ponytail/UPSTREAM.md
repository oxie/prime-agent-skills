# Ponytail provenance and adaptation

Source: [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail),
package 4.9.0, commit `356918eba965ee1eac64bd3a7f0dd02108350de5`.
Prime adaptation: `4.9.0-prime.1`. The complete MIT notice is retained in LICENSE.

Selectively adapted from the main, review, audit and debt SKILL.md files. The
ordered reuse ladder and evidence-based complexity/debt review are the useful
additions. Most general coding principles already exist in this workspace's
project-scoped instructions; those instructions were not made global or changed.

One on-demand skill replaces six upstream entries. Omitted: persistent activation,
lite/full/ultra enforcement, one-line/fewest-line targets, one-test ceiling,
silent requirement reduction, unsafe simplification examples, gain scoreboard,
help/update installer instructions, AGENTS/rule copies, manifests, executable
hooks, host plugins, statusline/config flags, MCP, and benchmarks/dependencies.
Read-only review and bounded source search are explicit. Existing tests, user
requirements and safeguards outrank simplicity. No global setting is changed.

Upstream benchmark figures are not Prime evidence. No upstream benchmark was
rerun and no speed, cost, code-size or safety improvement is claimed. In the
reviewed agentic scorer, feature correctness was a positive-LOC proxy and feature
safety was assigned unconditionally; the legacy gain card uses a different older
comparison. Historical figures cannot establish equivalent functional outcomes
or benefit against this workspace's existing coding discipline.

See AUDIT.md for completed local evaluation and limits. Contract tests check
instruction packaging, not mechanical compliance by future agents.
