# Higgsfield: selected connected asset workflow

Reviewed 2026-09-17. This is an original Prime adaptation of workflow ideas, not an
upstream installation, tested provider adapter or endorsement. The useful unit is
brief/reference roles -> connected still/shot prompts -> bounded execution handoff
-> actual output inspection -> responsive website delivery.

## Frozen sources

- [OSideMedia prompt library](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/tree/c0b73ab946df6658cca513db78bdc3909a655bfd), README 3.35.0.
- [Official Higgsfield skills](https://github.com/higgsfield-ai/skills/tree/d071406147a37b835bed09543d85ab3e9bd85c7d), VERSION 0.12.0; websites is a subdirectory, not a third repository.

`higgsfield-provenance.json` records selected file identities. Complete source
snapshots were identity-checked; substantive review was bounded full/selected/search
coverage, not a whole dependency audit. No upstream tests, CLI, generation, upload,
render, exploit, provider or model trial was run. Local documentation/fixture/native
loader tests establish their stated contracts, not creative effectiveness.

## Selection and corrections

OSide's shared direction, reference role/fidelity map, motion-ready views, stable
shot IDs and scoped overrides inform Image's workflow and the original Luma Desk
pack. Video adds temporal/revision and decoded-file handoff. Official asset-system
and Brandkit material inform authoritative-source precedence and dependency-aware
revisions. The provider guide distinguishes generic generation, server-enhanced
product/marketing work, opt-in identity training and paired explainer assembly.
Cinematic UI routes to those owners without replacing the host framework.

Corrected boundaries: prompts do not prove rendered fidelity; generated unseen
views do not establish real geometry; approval belongs to exact meaningful revisions;
uncertain jobs must not be blindly duplicated; schema, rights, uploads, total costs
and publication need actual authorization. No universal model superiority, filter
latency diagnosis, fixed success rate, mandatory shot count or animation quota.

Omitted: broad upstream routers, scripts/HTML player, memory/ledger/routing databases,
automatic source-file moves, permissions, hooks, installers, CI schedules, model
catalogue mirroring and paid smoke tests. Full Brandkit state/export tooling and
Higgsfield-hosted website/app orchestration are deferred, not claimed installed.
They offer real additional capability but need their separate dependencies, source
fixes, native/rendered validation and platform choice. The official snapshot advertises
nine skills but contains eight; do not use its installer as an integration shortcut.

## Primary policy context

Public [Terms](https://higgsfield.ai/terms-of-use-agreement) §4.4 and
[Privacy Policy](https://higgsfield.ai/privacy-policy) §§2.3,2.4,5.9 were inspected
on 2026-09-17. Standard terms permit commercial outputs and training on inputs/outputs;
Enterprise Agreement terms explicitly differ. Private/client marketing consent is a
separate issue from training. Deletion is not immediate removal from backups or
already-trained models. These are selected public statements, not legal advice,
account-specific contract verification or evidence of actual service behavior.
Recheck the actual agreement before restricted client/likeness work.
